# Audit du corpus de mots de lecture

Ce document présente les 167 mots actuellement proposés dans Devoiro. Il permet de contrôler les syllabes, les unités de lecture et la coloration générées par l’application. Le découpage exhaustif en graphèmes sera ajouté au fil de la validation lexicale du corpus.

- Les points médians matérialisent les séparations affichées.
- Les associations en **gras** correspondent aux sons complexes colorés dans l’application.
- Les lettres entre parenthèses correspondent aux lettres muettes affichées en gris.
- La colonne « Coloration » conserve le mot entier, sans séparation.

> Ce tableau reflète l’algorithme et les données pédagogiques actuels. Il sert aussi de base pour signaler et corriger les découpages discutables.
